## What We're Building

Restructure the 4 narrative outcome cards into 3 high-level ops category cards, each with example AI workers, per-worker outcomes, and differentiator tags.

## Key Decisions

1. **3 categories:** IT & Cloud Ops, Sales & Revenue Ops, Planning & Capacity Ops
2. **Layout:** 3 cards in a row, each card contains category header, 2-3 example workers with outcomes, and a category outcome type
3. **Outcome per example:** Each worker gets its own outcome stat (not one stat per card)
4. **Differentiator tags on workers:** Each example worker gets a tag like [Cross-Context], [Self-Learning], or [Takes Action]
5. **Summary callout below cards:** A strip reinforcing why SynOS is different from dashboards/alert tools
